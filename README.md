# LINK X Sistemas — HTML para GitHub Pages

## Publicación
1. Crea un repositorio en GitHub y sube `index.html` a la raíz.
2. Abre Settings → Pages → Build and deployment.
3. Selecciona Deploy from a branch, rama `main`, carpeta `/ (root)` y guarda.

## Cuentas de demostración
- Administrador: `admin@linkx.local` / `Admin123!`
- Colaborador: `colaborador@linkx.local` / `Demo123!`

## Limitación importante
GitHub Pages solo aloja sitios estáticos. Este archivo guarda datos en el almacenamiento local del navegador: los registros no se comparten entre usuarios o equipos. La contraseña y los permisos de esta demo pueden inspeccionarse o manipularse en el navegador; no uses datos reales.

Para permitir muchos usuarios desde distintos equipos con una tabla y dashboard compartidos, roles seguros y reportes exclusivos de administrador, conecta el HTML a un backend y una base de datos (por ejemplo Supabase/Firebase o una API propia). En producción, la contraseña administrativa se cambia en el backend o panel de autenticación, nunca dentro del HTML público.
